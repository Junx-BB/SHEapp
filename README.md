# 服装店积分收银系统（第一版）

## 启动方法

在项目目录运行：

```bash
npm start
```

也可以直接双击 `start.bat`。

启动后：

- 本机访问：`http://localhost:3000`
- 局域网访问：启动时会打印本机局域网地址，顾客扫码页面是 `http://电脑局域网IP:3000/scan.html`

## 数据保存位置

- 数据库：`data/store.db`
- 上传的收款码图片：`data/uploads/`

数据保存在当前电脑本地，刷新页面、退出程序、重启电脑都不会丢失。

## 已实现功能

- 顾客扫码填写手机号登记
- 店员结账：应收金额、积分抵扣、实付金额、收款码、确认收款
- 积分规则：实付金额每 100 元得 1 积分，四舍五入
- 当天积分当天不可用，第二天起可用
- 老客带新人：新人第一次消费时可绑定老客，双方同得积分
- 消费历史记录
- 撤销订单并自动调整积分
- 今日统计与客户查询
